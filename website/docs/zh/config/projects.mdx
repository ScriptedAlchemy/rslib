# projects

- **类型：** `string[]`
- **默认值：** `undefined`

`projects` 用于开启 Rslib 的工作区编排模式。  
当配置了该选项后，Rslib 会把当前配置视为工作区配置，并根据路径或 glob 规则解析子 Rslib 项目。

## 基本用法

```ts title="rslib.config.ts"
import { defineConfig } from '@rslib/core';

export default defineConfig({
  projects: ['packages/*'],
});
```

然后你可以在工作区根目录执行：

```bash
rslib build
rslib inspect
```

## 支持的项目项

`projects` 中的每一项可以是：

- 目录路径（Rslib 会在该目录中加载配置）
- 配置文件路径
- glob 模式（用于匹配多个目录或配置文件）

每一项都必须是非空字符串。  
如果 `projects` 中包含非字符串值，或全部为仅包含空白的字符串，Rslib 会抛出明确的配置错误。
在可能的情况下，错误信息也会包含对应配置文件路径，便于快速定位问题。

如果所有项目项都没有解析出任何子项目（例如 glob 没有匹配到目录），Rslib 会抛出 `No child projects found from workspace projects` 错误。
错误信息会包含未匹配的项目项模式，并在可能时包含对应配置文件路径。
错误里展示的项目项模式会先去除两侧空白后再输出。
如果配置里存在重复模式，错误信息会折叠为去重后的模式列表。

这些校验规则同样适用于嵌套工作区配置。
如果嵌套子配置不合法，错误信息会包含该子配置路径。

例如：

```ts title="rslib.config.ts"
export default {
  projects: ['packages/*', 'apps/**/rslib.config.ts', './examples/shared-lib'],
};
```

你也可以和顶层 `root` 选项一起使用。  
当工作区配置设置了 `root` 后，`projects` 中的路径会相对于该根目录解析。

## 嵌套工作区配置

子项目也可以继续使用包含 `projects` 的工作区配置。Rslib 会递归解析这些嵌套项目。

## 依赖构建顺序

在工作区模式下，`rslib build` 会按依赖顺序构建项目。

Rslib 会读取每个子项目 `package.json` 中的本地依赖关系，并在构建前进行拓扑排序。  
如果检测到循环依赖，Rslib 会抛出错误。
对于彼此没有依赖关系的项目，Rslib 会使用确定性的顺序执行。

## 项目过滤

可以通过 [--project](/guide/basic/cli#公共选项) 仅执行指定工作区项目：

```bash
rslib build --project @scope/pkg-a
rslib inspect --project @scope/pkg-*
```

`--project` 支持通配符和取反模式。
每个 `--project` 的取值都必须是非空字符串。
对于取反模式，`!` 后面的值也必须是非空（例如 `!@scope/legacy` 有效，而 `!` 无效）。
Rslib 会在匹配前自动去掉每个 `--project` 值两侧的空白字符。

使用项目过滤时：

- `rslib build --project ...` 会自动补齐所选项目的本地工作区依赖，并按依赖顺序构建。
- `rslib inspect --project ...` 仅检查被选中的项目。

因此，如果某个被选项目依赖另一个本地项目，即使该依赖项目被取反模式排除，也会在构建时被自动补齐并构建。
如果过滤后没有匹配到任何项目，Rslib 会报告过滤未命中，并输出可用的工作区项目名，帮助你快速定位可用取值。
过滤未命中的错误里也会包含规范化后的 `--project` 过滤规则（会去掉两侧空白，并规范化取反模式），方便快速定位是哪组模式导致所有项目被排除。
如果传入了重复的 `--project` 规则，过滤未命中的错误信息会折叠为去重后的规则列表。

## 注意事项

- 同一个配置文件中不能同时使用 `projects` 和 `lib`。
- 在工作区模式下，将 `lib` 显式设为 `undefined` 与省略 `lib` 的行为一致。
- 解析后的工作区项目名必须唯一。Rslib 会优先使用 `package.json` 中的 `name` 作为项目标识；若不存在，则回退为项目目录名。
- 工作区模式当前支持：
  - `rslib build`
  - `rslib inspect`
- 工作区模式暂不支持 `rslib build --watch` 和 `rslib mf-dev`。
